# ChatGPT listing package

The root `plugin.json` and `mcp.json` are the portable Agent Plugins package format. They are prepared for the public read-only WallpaperHub help app, but must not be submitted before the deployed `/mcp` endpoint has been verified.

The manifest has five positive and three negative MCP review cases. The real video walkthrough URL is intentionally omitted until there is a deployed service to record. Do not replace it with a placeholder.

Required listing URLs:
- Website: https://wallpaperhub-morocco.vercel.app
- Support: https://wallpaperhub-morocco.vercel.app/support.html
- Privacy: https://wallpaperhub-morocco.vercel.app/privacy.html
- Terms: https://wallpaperhub-morocco.vercel.app/privacy.html#terms
- MCP server: https://wallpaperhub-morocco.vercel.app/mcp

The submission portal is the source of truth for current fields, validation, domain verification, identity verification, and review status.
