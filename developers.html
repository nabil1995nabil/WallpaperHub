ورقة الاستخدام السريع

طلب واحد للوصول إلى الخلفيات المنشورة.

GET /api/v1/wallpapers
مثال JavaScript
const response = await fetch("/api/v1/wallpapers", {
  headers: {
    "X-API-Key": "YOUR_API_KEY"
  }
});

const result = await response.json();
console.log(result.data);
01أرسل المفتاح في ترويسة X-API-Key فقط، ولا تضعه في الرابط.
02طلبات المتصفح تحتاج إلى النطاق الذي اخترته عند إنشاء المفتاح.
